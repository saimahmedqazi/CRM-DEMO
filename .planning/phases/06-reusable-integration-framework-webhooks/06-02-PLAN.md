<objective>
Implement HMAC-SHA256 signature verification, idempotency check, and modular integration adapters for WhatsApp Business, Meta Ads, Email, and Phone PBX systems.

Purpose: Guarantee tamper-proof, deduplicated lead ingestion across all major commercial messaging and advertising platforms.
Output: Webhook security engine, adapters, webhook route handler, and passing unit tests.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: HMAC Webhook Verification & Adapters</name>
  <files>lib/integrations/webhook-verifier.ts, lib/integrations/adapters/whatsapp-adapter.ts, lib/integrations/adapters/meta-ads-adapter.ts, lib/integrations/adapters/email-adapter.ts, lib/integrations/adapters/phone-logger-adapter.ts, app/api/v1/webhooks/[provider]/route.ts</files>
  <action>
    Implement `lib/integrations/webhook-verifier.ts`:
    - `verifyHmacSha256(rawBody, signatureHeader, secret)`: Computes crypto HMAC-SHA256 and compares using constant-time `timingSafeEqual`.
    - `checkAndRecordIdempotency(orgId, provider, idempotencyKey)`: Prevents replay attacks.
    Implement adapters:
    - `whatsapp-adapter.ts`: Parses Meta WhatsApp Cloud API payload (from, name, text message, timestamp) -> normalizes phone -> creates lead.
    - `meta-ads-adapter.ts`: Parses Meta Lead Ads payload (ad_id, form_id, field_data [full_name, phone_number, email], created_time) -> creates lead with campaign attribution.
    - `email-adapter.ts`: Parses inbound email payload (sender, subject, plain_body, received_at) -> creates lead.
    - `phone-logger-adapter.ts`: Parses PBX call log event (caller_id, duration_seconds, call_status ['missed', 'answered', 'voicemail'], clinic_did) -> creates lead or follow-up task.
    Implement `app/api/v1/webhooks/[provider]/route.ts`:
    - GET: Meta webhook challenge verification (`hub.challenge`, `hub.verify_token`).
    - POST: Verifies signature, validates idempotency, dispatches to appropriate adapter, returns 200 OK.
  </action>
  <verify>Check TypeScript and build compilation</verify>
  <done>Webhook security engine and adapters operational.</done>
</task>
